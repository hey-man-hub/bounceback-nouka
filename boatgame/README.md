# BounceBack Nouka

A small browser game about local river life in Bengal. *Nouka* is what people in Bengal call a boat.

**Play it online:** https://hey-man-hub.github.io/bounceback-nouka/

## Game modes

**Career mode** - sail your nouka down the river.
- Dodge rocks, fish piles and plastic. Every hit costs a heart, and three hearts sink your nouka.
- Stop at the ports along the top bank, pick up a passenger and deliver them to the next port for bonus points.
- The further you sail, the faster the river flows.

**Fishing mode** - cast your line and keep the fish inside the catch box to fill the green bar.
- Rarer fish move faster and the catch box gets smaller.
- Collect all 30 river fish.

## Controls

| | Career | Fishing |
|---|---|---|
| Move / aim | W / S or Up / Down arrows (change lane) | Mouse or arrow keys |
| Speed | D / Right arrow = faster, A / Left arrow = slower | - |
| Action | F = pick up / drop off passenger | Click or Space = cast, hold to move the catch box right, release to move it left |
| Other | H = how to play, P = pause, R = restart | C = fish collection, H = how to play, P = pause, R = restart |

On phones there are on-screen buttons in both portrait and landscape.

## Run it locally

No build step and no dependencies. Download the files and open `index.html` in any modern browser.

## Project files
